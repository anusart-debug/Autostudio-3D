# ข้อมูลสายรถเมล์ต่อโลเคชั่น

ค่าตั้งต้นอยู่ใน `src/js/10-data.js` → `LOCATIONS[].bus`
ผู้ใช้แก้ได้เองในแอป (เก็บใน localStorage `as3d_bus`) — ที่นี่คือ**ที่มาและระดับความเชื่อถือ**

## หลักการนับสาย (เปลี่ยนใน v39)
เดิมนับจาก **ถนนที่อยู่ในรัศมี** ซึ่งผิดหลักสำหรับงาน OOH เพราะรวมสายที่จอดป้ายหน้าสื่อจริง
เข้ากับสายที่แค่ขับผ่านถนนแถวนั้น

**ตอนนี้: หาป้ายรถเมล์ที่ใกล้จุดสื่อที่สุดก่อน แล้วเอาเฉพาะสายที่จอดป้ายนั้น**

## คำเตือนก่อนใช้กับลูกค้า
- **เลขสายอยู่ระหว่างเปลี่ยนระบบ** จากเลขเดิม ขสมก. เป็นรหัสใหม่กรมการขนส่งทางบก
  เขียนคู่กันเสมอ `77 (3-45)` — คนเช็ก ViaBus เห็นรหัสใหม่ คนมองข้างรถมักเห็นเลขเดิม
- บางสายมีเฉพาะรหัสใหม่ (`3-53`, `3-54`, `4-35`, `2-34L`, `2-34R`) — ไม่ใช่พิมพ์ผิด
- ตัวอักษรต่อท้ายมีความหมาย: `E` ทางด่วน · `L/R` วนซ้าย/ขวา · `ก` สายย่อย
- **กับดัก: บล็อก "Adjacent lines" ของ transitbangkok ไม่ใช่สายที่จอดป้ายนั้น** แต่เป็นสายที่วิ่งแถวนั้น
  ตรวจแล้วพบ `183`, `76 (4-14)`, `3-53` โผล่ในบล็อกนี้ของเซ็นทรัลเวิลด์ ทั้งที่หน้าสายของมันเองไม่มีป้ายแถวนั้น
  **ห้ามใช้กับงานขาย** ต้องดูลำดับป้ายในหน้าของสายนั้นเอง
- **route.in.th มีข้อมูลค้าง** — ลิสต์สาย `513` ที่เซ็นทรัลเวิลด์ ทั้งที่ transitbangkok ไม่มีสาย 513 แล้ว

## เซ็นทรัลเวิลด์ / ราชดำริ — ตรวจใหม่ทั้งหมดใน v39
**ป้ายจริงทั้งหมดอยู่บนถนนราชดำริ ไม่ใช่พระรามที่ 1** (ยืนยันจาก Longdo ทั้งสองจุด)
สายที่วิ่งพระรามที่ 1 ผ่านหน้าห้างด้านใต้ **ไม่ได้จอดป้ายชื่อเซ็นทรัลเวิลด์**
แต่จอดที่สยาม / รพ.ตำรวจ / เซ็นทรัลชิดลม — ผู้ชมแบบรอป้ายกับแบบขับผ่านคนละคุณค่ากัน

**ป้ายที่เกี่ยวข้อง:** ห้างเซ็นทรัลเวิลด์ · เซ็นทรัลเวิลด์ (จุดที่ 1) · (จุดที่ 2) · Bigc Rajdamri · Peninsula Plaza
(transitbangkok เก็บเป็น 3 ระเบียนแยกกันทั้งที่ห่างกัน ~100 ม. ต้องรวมทั้งสามถึงจะครบ)

## สถานะข้อมูล OSM (taginfo Geofabrik ไทย, ก.ย. 2569)
- `route=bus` = **697 relation** · BMTA 379, TSB 279, smart bus 103, DLT 18
- `highway=bus_stop` = **8,050 node**
- เทียบกับเครือข่ายจริงราว 250–270 สายในกรุงเทพ แปลว่าเก็บแยกขาไป-ขากลับ และครอบคลุมพอสมควร
- **ยังยืนยันไม่ได้** ว่า `ref` ใช้เลขเดิมหรือรหัสใหม่ และอัปเดตล่าสุดเมื่อไร
  → **อย่าใช้ OSM เป็นแหล่งเดียวสำหรับเลขสายที่ส่งให้ลูกค้า**
  ใช้เป็นชั้นเส้นทางบนแผนที่ ทับรายการที่ตรวจจาก transitbangkok
