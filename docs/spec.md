# สเปกและการตัดสินใจหลัก

> ย้ายมาจากโปรเจกต์ Claude ตอนแยกเป็นซอร์สโค้ด — เก็บเหตุผลเบื้องหลังไว้ให้คนที่มาแก้ต่อ

## แอปนี้คืออะไร
ไฟล์ HTML ไฟล์เดียว **เขียนคำสั่ง (prompt) ระดับมืออาชีพสำหรับสร้างภาพโฆษณา OOH**
**ไม่เจนภาพเอง · ไม่มีช่องใส่ API Key · ไม่ส่งข้อมูลผู้ใช้ออกจากเครื่อง**
เปิดจาก `file://` ได้เต็มรูปแบบ

## การตัดสินใจที่อย่ากลับไปทำใหม่

### ถอดระบบ API ออกทั้งหมด (v32)
คำสั่งผู้ใช้: *"เอาหัวข้อการใส่ API ออก ไม่ได้ใช้งาน เจนจากระบบ เพื่อความปลอดภัยต่อผู้ใช้งาน
ใช้แค่การคัดลอกคำสั่งที่เขียนโดยสมบูรณ์อย่างมืออาชีพ"*

เหตุผลเชิงเทคนิคที่สนับสนุน — ทดสอบมาครบแล้วทุกเจ้าใน v1–v31:

| ทาง | ผลจริง |
|---|---|
| Gemini free tier | `429 ... limit: 0` = ปิดโควตา ไม่ใช่ใช้หมด · รอไม่ช่วย ต้องเปิดบิลลิ่ง |
| Pollinations Kontext | ต้องมี token · เอกสารทางการผิด 3 ครั้ง (endpoint ตาย / โมเดลย้าย / auth เปลี่ยน) |
| OpenAI gpt-image-1 | ต้องมีเครดิต + เบราว์เซอร์บล็อก CORS |
| Leonardo / Ideogram | เสียเงิน หรือบล็อก CORS |

→ ทาง handoff (คัดลอกคำสั่ง + แนบภาพเองในเว็บที่ล็อกอินอยู่) คือทางเดียวที่ได้ผล 100%

### กฎการส่งมอบ: ใส่เลขเวอร์ชันเสมอ
เคยเสียเวลาทั้งสองฝ่ายเพราะผู้ใช้รันไฟล์เก่าแล้วรายงานบั๊กที่แก้ไปแล้ว
**โชว์เลขเวอร์ชันบนหัวจอ** และบอกผู้ใช้ทุกครั้งว่าต้องเห็นเลขอะไร

## คำสั่ง 3 แบบ สลับอัตโนมัติ
```
activePrompt() = adReady() ? buildAdPrompt()
               : editMode() ? buildEditPrompt()
               : buildPrompt()
```
มีฉบับไทยคู่กันทุกตัว (ไทยไว้อ่านตรวจสอบ ส่งจริงใช้อังกฤษเพราะแม่นกว่า)

- `hasSketch()` มีภาพสื่อต้นแบบ · `hasAd()` มีอาร์ตเวิร์กใบที่ 2 · `adReady()` มีครบสองใบ

### โหมดเปลี่ยนโฆษณา
บอก AI ชัดว่า IMAGE 1 = ภาพสื่อที่จะแก้ · IMAGE 2 = อาร์ตเวิร์กใหม่
สั่งลบโฆษณาเดิมออกให้หมดแล้ววางอันใหม่ในจุดเดิม

- `#adFit` = `relayout` (ค่าเริ่มต้น จัดองค์ประกอบใหม่ให้เต็มกรอบ ห้ามยืด) / `fit` / `stretch`
- `#adKeepScene` ไม่ติ๊กเป็นค่าเริ่มต้น = จัดฉากและแสงใหม่ตามขั้น 4–6 ด้วย

## สื่อ 7 ประเภท — คำสั่งรู้จักชนิดสื่อ
`wrap` · `dd` · `bus3d` · `shelter`(นิ่ง) · `muvmi` · `billboard`(นิ่ง) · `ledscreen`(นิ่ง)

`subjInfo()` / `heroClause()` / `angleText()` เปลี่ยนคำนามประธานตามสื่อที่เลือก
สื่อที่ตั้งกับที่จะเติม negative guard อัตโนมัติ และแปลงมุมกล้องจาก "hood height"
→ "street level looking slightly up at it"

> บั๊กเก่า: เลือกบิลบอร์ดแต่คำสั่งเขียนว่า "vehicle" ทำให้ AI เน้นรถแทนป้าย

## Reference DNA (แผง 01B)
canvas ในเครื่อง: ย่อ 200 px → ตัดพื้นหลังด้วยสีมุมซ้ายบน (±16) → quantize bucket ละ 32
→ รวม bucket ชื่อสีเดียวกัน → แมปชื่อสี 33 สีด้วย **Euclidean RGB ธรรมดา**
(luma weighting ทำให้ white กลายเป็น cream) → สีหลัก/รอง/เสริม (ตัด luminance ≤ 60 = กระจก+ยาง)
→ bounding box → aspect ratio → ชนิดตัวถัง + ทิศทาง
